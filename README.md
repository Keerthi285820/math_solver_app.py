# 🧠 Smart Math Solver

A Streamlit web app that helps solve arithmetic problems, simplify algebraic expressions, and solve equations interactively.

Features

Arithmetic Evaluator: Compute results of numeric expressions.

Algebra Simplifier: Simplify algebraic expressions using SymPy.

Equation Solver: Solve equations for x.

Interactive and user-friendly interface.

Installation

Clone the repository:

git clone https://github.com/<your-username>/smart-math-solver.git
cd smart-math-solver


Install dependencies:

pip install streamlit sympy

Usage

Run the app:

streamlit run smart_math_solver.py


Select the solver type (Arithmetic, Algebra, Equation).

Enter your expression in the input box.

Click Solve to get results.

Works with numbers, variables, and algebraic expressions.
